# ryancurrah/homebrew-tap

Homebrew casks for [mcp-gimp](https://github.com/ryancurrah/mcp-gimp) — drive
GIMP 3 from an MCP client.

```bash
brew tap ryancurrah/tap

brew install --cask mcp-gimp          # the MCP server
brew install --cask gimp-mcp-plugin   # the GIMP 3 plug-in (macOS)
```

The casks in this repository are generated on each `mcp-gimp` release. Edit
them there, not here.
